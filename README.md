# Cherry Rush
It is a game like you rush collect all the cherries before the time out and you win let is gooo 
## Gameplay

* Collect normal cherries to increase your score.
* Avoid danger cherries.
* Reach the required amount of cherries before time ends.
* Survive through multiple levels with increasing difficulty.

## Controls

| Key             | Action     |
| --------------- | ---------- |
| Left Arrow / A  | Move Left  |
| Right Arrow / D | Move Right |
| Space           | Jump       |

## Levels

### Level 1

* Goal: Collect cherries
* Lose if:

  * You collect 10 danger cherries
  * Timer reaches 0

### Level 2

* Faster gameplay
* More difficult challenge
* Goal: Collect cherries
